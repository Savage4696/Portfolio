## 🌟 Overview

A modern, high-performance personal portfolio built with **React**, **Vite**, and **Framer Motion**. Designed with iOS-inspired glassmorphism, hardware-accelerated 3D card tilt physics, and interactive neural canvas animations.

---

## 🛠 Tech Stack

- **Frontend**: React 18, Vite, Framer Motion, Lucide React
- **Styling**: Vanilla CSS with modern fluid typography & glassmorphism design system
- **PDF Resume**: Programmatically compiled clean resume engine
